# Система управления задачами

Учебный проект на Python: создание задач, назначение их пользователям,
статусы, канбан-доска, тесты, мониторинг и развертывание.

## Запуск

    python main.py

Нужен Python 3.8 или выше. Дополнительные пакеты не нужны.

## Учёт времени

Модуль `time_tracking.py`: таймеры по задачам, подсчёт времени и отчёты.
Подробнее — в [руководстве пользователя](TIME_TRACKING_GUIDE.md).
